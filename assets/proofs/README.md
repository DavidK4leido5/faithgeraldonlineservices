# Transaction proof images

Drop real receipt screenshots here, named exactly:

    proof-01.png ... proof-08.png

Recommended: portrait screenshots (e.g. 1080x1440), PNG or JPG.

The page works without them: each missing image renders a labelled
placeholder and its lightbox trigger is disabled, so no empty viewer opens.
Adding the files is all that is required, no code change.

Privacy: crop or blur account numbers, reference numbers, full names,
phone numbers and balances before committing. The page never repeats
receipt details as text.
